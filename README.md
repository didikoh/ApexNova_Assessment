# ApexNova Senior Software Engineer Assessment

This repository contains the completed assessment materials for the Senior Software Engineer application.

## Repository Structure

### Background Check

Completed background check and candidate information requirements.

The submitted information and answers are available in two formats:

- `Background check/interview_candidate_information.html` — formatted HTML version
- `Background check/infomation.txt` — plain text version

### Personality Test

Completed personality assessment results.

- DISC assessment
- MBTI assessment

### Question 1

PHP array generation and lookup exercise.

The solution generates 100,000,000 random samples while treating duplicated values as a single number, as permitted by the provided assessment template.

Random values are stored as array keys to provide efficient membership lookup while keeping memory usage within the required limit.

### Question 2

Laravel 11 Product Inventory Management REST API.

Includes:

- Product, Category, and Supplier models and relationships
- Product CRUD API
- Filtering and pagination
- Laravel Sanctum authentication
- Form Request validation
- API Resources
- Eloquent scopes and accessor
- Soft deletes
- Migrations and seeders
- Feature tests
- Docker setup
- OpenAPI / Swagger documentation
- Caching
- Rate limiting

See [`Question_2/README.md`](Question_2/README.md) for full setup instructions, API documentation, testing, and implementation details.

### Question 3

Code review exercise covering security, validation, authorization, database access, performance, API response design, and maintainability.
